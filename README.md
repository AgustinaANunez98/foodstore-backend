# Food Store - Backend

Food Store es una aplicación para la gestión de una tienda de alimentos.
Permite administrar usuarios con distintos roles, productos con sus 
respectivas categorías y pedidos con sus detalles.

La aplicación se desarrolla como Trabajo Práctico Integrador de la materia Bases de Datos II,
con el objetivo de implementar los conceptos aprendidos durante la cursada,
como el uso de bases de datos NoSQL y la baja lógica.

## Objetivo del proyecto

El objetivo de esta aplicación es implementar una conexión entre un backend desarrollado en Java y
una base de datos NoSQL alojada en MongoDB Atlas. A partir de esta conexión se realizarán operaciones CRUD 
sobre los datos de la aplicación, respetando la baja lógica.

Además, se implementará un mecanismo automatizado de respaldo de la base de datos para garantizar 
la recuperación y conservación de la información.
